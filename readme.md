# Deutsche Bank Wealth Management

A full-stack wealth management web application developed as part of my freelance work.

The project involved building a dashboard-based application for presenting investment-related information, including bonds and pre-IPO investments. I worked across the frontend and backend, using Next.js, React, TypeScript, Express.js, and MongoDB.

## Project Overview

The main focus was to build a structured interface where users could navigate financial information and access investment-related features without the application becoming difficult to use.

Alongside the dashboard, the project included PDF generation with barcode support. This required working beyond the frontend and connecting the application's different parts to support the required functionality.

I worked on this project individually during the development period, from January to July 2026.

## Key Features

- **Wealth Management Dashboard** — An organized interface for presenting financial and investment-related information.
- **Bond Investments** — A dedicated section for bond-related investment information.
- **Pre-IPO Investments** — Functionality for presenting pre-IPO investment opportunities and their related details.
- **PDF Generation** — Generation of PDF documents with barcode support.
- **Frontend and Backend Integration** — Connecting the user interface with server-side functionality and database operations.
- **Component-Based UI** — Using Ant Design components to maintain consistency across the application.
